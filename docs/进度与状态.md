## 阶段 2 要做的事

目标：把现在「把结果画成文字」换成「真正的文件列表」。

1. 在 `src/ui/FileListView.h/.cpp` 建 ListView 封装，样式设 `LVS_OWNERDATA | LVS_REPORT`，
   配 `LVS_EX_FULLROWSELECT | LVS_EX_DOUBLEBUFFER`。
2. 实现 `LVN_GETDISPINFO`（即 `NMLVDISPINFO`）回调，按行号从 `m_result.entries` 取数据，
   **不要在控件里存全部条目**。
3. 列设计（按用户既有习惯：名称列自适应吃剩余宽度，其余固定）：
   | 列 | 宽度策略 |
   |---|---|
   | 名称 | 自适应，保底 260 |
   | 大小 | 固定 110 |
   | 类型 | 固定 110 |
   | 修改日期 | 固定 160 |
4. 双击文件夹 → 进入该目录（先做最简单的，不接历史栈）。
5. 图标接入放到阶段 6（阶段 2 先显示系统默认文件夹/文件图标即可，避免拖慢）。

**阶段 2 验收标准**：
