## 关于「又快又像」的实现方式（已落地部分）

| 资源管理器的慢点 | 本项目的做法 |
|---|---|
| 缩略图预加载 | 不做缩略图，只取系统图标 |
| 图标每次都查磁盘 | 按扩展名缓存，`SHGFI_USEFILEATTRIBUTES` 不访问文件 |
| 列表控件内部维护全部行 | `LVS_OWNERDATA` 虚拟模式，数据在后台线程 |
| 预览窗格 / 详细信息窗格 | 不做 |
| 自动分组 / 自动排序 | 不做 |
| 第三方外壳扩展 | 不加载（本项目不用 ShellView，只自己画） |
