调研结论（详见 `docs/进度与状态.md` 的「C8 方案」一节）：

- `ComputeNewName`（270 行）和 `BuildPreviewRows`（290 行）**不是纯函数**：
  它们通过 `::SendMessage` + `kRf*` 控件 ID 直接读界面控件取规则；
- 用到的 17 个助手函数在**匿名命名空间**（内部链接），第二个翻译单元用不了；
- 助手还依赖 `kInvalidChars` / `kMaxNumberDigits` / `kMaxFileNameLength` 三个常量。

两步方案：

1. **C8-1**：抽出 `RenameRules` 值对象（可复用现有 `RenameTemplate` +
   `CaptureCurrentRules`），让 `ComputeNewName(const RenameRules&, ...)` 不再读控件。
   这是**行为敏感改造**，需要先准备一批"改名前 → 改名后"的对照用例（前缀/后缀/查找替换/
   正则/序号/起始步长位数/大小写/扩展名处理/非法字符/保留名/重名冲突）。
2. **C8-2**：助手提升为外部链接，`ComputeNewName` / `BuildPreviewRows` 搬到
   `BatchRenameRules.h/.cpp`，原文件只留 UI/绘制/消息处理。

## 8. 自动化测试方法（本机已验证可行）

用户文档里记过：自动化环境抢不到前台，**不要依赖真实鼠标**。可行的是 `PostMessage` + 读日志：

- **命令**：向主窗口 `PostMessage(WM_COMMAND, <命令号>, 0)`。
  常用命令号（定义在 `ui/MainWnd.h`）：
  `3101` 复制、`3102` 剪切、`3103` 粘贴、`3104` 删除、`3105` 刷新、
  `3107` 全选、`3108` 上一级、`3201` 打开。
- **找窗口**：`EnumWindows` 按进程 PID + 类名 `FileExplorerMainWindow`（比 `FindWindow` 可靠）。
- **读日志**：用 UTF-8 读（`StreamReader(..., Encoding.UTF8)` + `FileShare.ReadWrite`），
  中文匹配才对得上；`Select-String` 默认按 ANSI 读会匹配不到中文。
- **右键菜单**：找到子窗口 `SysListView32`，`PostMessage(list, WM_CONTEXTMENU, list, MAKELPARAM(screenX,screenY))`，
  菜单弹出后进程存活即说明构建菜单没崩；再用 `WM_CANCELMODE` 收掉，或直接杀进程。
- **文件操作端到端**：造一个临时目录 → 启动程序 → 发 `3107,3101,3103` →
  检查目录里出现 `xxx - 副本` 和日志「文件操作完成」。

## 9. 环境与工具陷阱（都踩过）

1. **不要用 PowerShell 的 `Get-Content` / `Set-Content` 改 UTF-8 源文件**。
   本机 PowerShell 默认按 GBK 解码，会把中文注释写成乱码、还可能吞掉换行
   （`ContainerExtract.cpp` 和 `Explorer.vcxproj` 都被这样写坏过，靠 git checkout / 重写恢复）。
   批量改文件用**Python 脚本**（`io.open(..., encoding='utf-8', newline='')`），
   小改用 `edit` 工具。
2. **改 `Explorer.vcxproj` 用 `edit` 工具**，不要用 PowerShell 读写。
3. **编译前先关运行中的实例**：`bin\x64\Debug\FileExplorer.exe` 被占用会报
   `LNK1104`。先 `CloseMainWindow()`（会正常保存配置），再编。
4. **测试不要用无关联扩展名**（如 `.zzz`）：程序回退 `ShellExecute` 时 Windows 会弹
   `OpenWith.exe`（"选择打开方式"）。曾因自动化连发命令产生 332 个 `OpenWith.exe`。
   要测"打开文件"，用系统已有关联的类型，或干脆只测到"已提取到临时文件"为止。
5. **`%APPDATA%\FileExplorer\settings.json` 是用户真实数据**：
   测试前备份、测试后还原。目录里还有一个 `settings.json.bad`（历史坏档，含完整旧配置），
   不要删，用户可能要用它对照。
6. **窗口类名只有一个来源**：`ui::kMainWindowClassName`（`ui/WindowRelay.cpp` 定义）。
7. **`settings.json` 并发**：已加命名互斥 `Local\FileExplorer.SettingsSave`，不要去掉。
8. **版本号**：只改 `res/version.h` 一处；`res/app.rc` 里是宏引用，不用动。
